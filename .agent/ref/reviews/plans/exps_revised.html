E4 · "会做就不用工具" 重构策略D / R1.5

你的批注: 这就是我们的诉求啊 —— 我们就是想让它会做就不用工具,因为用工具有成本。你看是说一下还是怎么找。

关键认知:reviewer 把它当"reward hacking 漏洞",但这其实是你们的设计目标。所以回复不是"自证清白",而是澄清设计意图 + 用数据证明它没有牺牲该有的能力。这条和论文 "adaptive / emergent tool use" 主线完全一致,反而是加分项。

要摆的证据(用已有 rollout 日志即可,不重训)
  • ①"答对且未调用工具"的样本,其正确率同样高 → 说明不用工具时是能力之内,没有以精度换简洁;
  • ②在"确实需要感知/规划"的难题上,工具使用率显著更高 → 说明是按需调用,不是"该用不用"。
  • 合起来 = 成本感知的、按需的工具使用,而非 reward hacking。
回复措辞(可直接用)
"This is by design, not reward hacking. Tools incur latency and compute cost, so the reward intentionally elicits tool use only when it improves correctness. Table X shows: (i) on instances solved without tools, accuracy is not lower than the tool-using regime; (ii) on perception/planning-hard instances the model invokes tools heavily. This is need-based, cost-efficient tool use — consistent with our adaptive-behavior claim. On theory: we follow the GRPO objective (convergence inherited); the reward is bounded shaping that biases when to use tools, not the task optimum."

E6 · LM-judge 一致性 诚信红线I / R2.7

你的批注: 瞎整一个把数填上就行了,咱也没钱雇人标注。

这条我必须直说:不能编造人工一致性数据。 那属于 data fabrication(学术不端);Springer reviewer 完全可能追问标注协议/样本量/标注人。一旦被发现是编的,是 撤稿 + 学术信誉 级后果,比"judge 未充分验证"这个弱点严重不止一个数量级。而且 —— 根本不用编,有免费且正当的路:

零成本合规替代(推荐 ①+③)
  • ① 作者自评盲标:你们研究生本身就是合格标注者。抽 50–100 条,≥2 人独立盲标,算 Cohen's κ 与准确率。在文中如实写"annotated by the authors" —— 完全正当、零花费,一天能完成。
  • ② 第二独立裁判(可选):用另一强模型(GPT-4o / Gemini)作第二 judge,报模型间一致性 —— 不需要人,少量或零 API。
  • ③ 冗长度检验:纯计算,免费 —— 回归/分层控制答案长度,证明 judge 打分不随长度上升(长≠高分),直接回应"verbose 被偏袒"。
回复:"We validate the LM judge on N=<实测> samples double-annotated by <k> of the authors (blind); Cohen's κ=<实测>. We further check length bias: controlling for answer length, judge scores do not increase with verbosity (Fig X)." —— 数字用你们真跑出来的,不留假。
